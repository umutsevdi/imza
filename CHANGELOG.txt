CHANGELOG
-------------------------------------------------------------------------------
0.1.3 - 2026-09-09
-------------------------------------------------------------------------------
[https://github.com/umutsevdi/ursa/releases/tag/v0.1.3]

Changes:
  - Improved Windows startup time.
  - Improved response rendering performance.
  - Reduced memory usage when preparing modal content.
  - Improved chat rendering performance.
  - Fixed review horizontal scrolling and focus.
  - Session list now loads in the background from a session index.
  - Added cross-process file locking for config and session files.
  - Concurrent ursa instances no longer overwrite each other's config changes.
  - Fixed title-generation subagent ignoring the configured reasoning effort.
  - Various internal cleanups and code deduplication.

-------------------------------------------------------------------------------
0.1.2 - 2026-09-08
-------------------------------------------------------------------------------
[https://github.com/umutsevdi/ursa/releases/tag/v0.1.2]

Changes:
    - Added CLI commands.
    - Rewritten permission system.
       - Permissions can be set using CLI options or using user responses.
       - Added shell command evaluation based permissions.
       - Added directory access management.
    - Performance improvements on large conversations.
    - Performance improvements on large diff reviews.
    - Added headless mode.
    - Various other small bug fixes.
