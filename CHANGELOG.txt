CHANGELOG
-------------------------------------------------------------------------------
0.5.0 - 2026-09-30
-------------------------------------------------------------------------------
<https://github.com/umutsevdi/imza/releases/tag/v0.5.0>

Changes:
  - Redesigned Plan Mode. Plan mode now generates a spec document on demand on
  side pane. You can attach notes to any block or section in the document 
  and send them as one revise request to update. You can also request for update
  via chat messages.
  Plans and it's revisions are stored in session data.
  - Added the /compact and /make-skill commands.
  - Added multi-modal input support for image types and PDF files.
  - Added support for charts.
  - Added select-to-copy.
  - Fixed a hidden Sidechat intercepting clicks and keystrokes meant for the
main chat.
  - Clicking the plan document or chat pane now moves focus between them on
the Plan tab.
  - Fixed keyboard focus not returning to the chat after closing a dialog.
  - Added syntax highlighting for Markdown, YAML, TOML, C#, and XML files,
registered TSX and Jupyter notebook files.
  - fs.write now creates missing parent directories instead of failing.
  - A welcome banner is shown in the chat when the app opens, until the
first message is sent.
  - Fixed a crash when a mentioned skill is denied by project permissions.
  - Fixed update downloads rejecting certain successful server responses.
  - Fixed the tab menu highlighting the wrong tab when a session opens in
Build mode.

-------------------------------------------------------------------------------
0.4.1 - 2026-09-24
-------------------------------------------------------------------------------
<https://github.com/umutsevdi/imza/releases/tag/v0.4.1>

Changes:
  - Tool calls show a unified Planning → Executing → Executed status, so the
agent no longer looks idle while it streams a tool call's arguments.
  - Fixed a crash when Lua returns a list containing mixed value types.
  - Fixed a bug that caused `tool.grep(...)` to fail.

-------------------------------------------------------------------------------
0.4.0 - 2026-09-22
-------------------------------------------------------------------------------
<https://github.com/umutsevdi/imza/releases/tag/v0.4.0>

Changes:
  - NEW: Rewritten the agent tool call system. See: <https://github.com/umutsevdi/imza/discussions/1>
  - Tool call results use custom renderers depending on return types.
  - Clearer tool error messages: failed file lookups show the resolved path,
edits report the searched text, and the Lua tool description documents the
ask call shape and the return-over-print preference.
  - UI polish.
  - Internal cleanup: removed an unused legacy field from stored tool
results.

-------------------------------------------------------------------------------
0.3.0 - 2026-09-18
-------------------------------------------------------------------------------
<https://github.com/umutsevdi/imza/releases/tag/v0.3.0>

Changes:
  - Fixed high idle CPU usage caused by constant chat timeline redraws.
  - Improved system, subagent, compaction, and review prompts based on research
into other coding agents.
  - Increased maximum timeout for streams. Added retry for server errors (HTTP 
408, 409, 5xx).
  - Imza sends a recognizable user-agent on provider requests.
  - Loaded sessions continue in place, active chats are locked against other 
imza processes.
  - Added `Sidechat`, a place to ask questions without disrupting the main 
agent. The Sidechat is toggled with Ctrl+S, its context reloads from the main
chat on the next prompt. 
  - Session explorer and Connect now deletes with the Del key, so filtering no
longer triggers deletions.
  - Updated Subagent model picker.
